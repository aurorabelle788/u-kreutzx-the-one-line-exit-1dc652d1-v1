A one-line resignation letter from an escape-room attendant who spent three
years looking for the exit — and finally found it in the letter itself.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt` with
no trailing newline, after checking it passes the gate: 1–140 characters,
exactly one line, not only whitespace.
